# TV Браузер — Android TV

Небольшой исходный проект браузера для Android TV / Google TV. Интерфейс на русском, написан на Java с использованием системного WebView. Нет сторонних библиотек, рекламы и трекеров, встроенных в приложение.

## Возможности

- Управление обычным пультом: экранный курсор, перемещение стрелками, клик кнопкой OK.
- Отдельный режим фокуса для кнопок панели и поддержка мыши/клавиатуры.
- Адресная строка с поиском Google и распознаванием доменов.
- История назад/вперёд, домашняя страница, обновление.
- Локальные закладки (до 100), восстановление последней открытой страницы.
- Мобильная и настольная версии сайтов (переключаемый User-Agent).
- HTML5-видео с полноэкранным режимом через WebChromeClient.
- Прокрутка CH+/CH−, PAGE UP/DOWN, либо из меню ⋮.
- Возможность удалить историю, cookies, кэш и хранилище сайтов (закладки сохраняются).

## Сборка APK

1. Установите **Android Studio** и Android SDK Platform **35**, JDK **17**.
2. Откройте в Android Studio папку `TVRemoteBrowser` через **Open**.
3. Дождитесь **Gradle Sync**. Проект использует Android Gradle Plugin `8.9.2` и Gradle `8.11.1` (указан в `gradle/wrapper/gradle-wrapper.properties`).
4. Выполните **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
5. Полученный файл будет в `app/build/outputs/apk/debug/app-debug.apk`.
6. Перенесите APK на телевизор и установите через ADB (`adb install -r app-debug.apk`) либо разрешённым на устройстве способом.

**Примечание о Gradle Wrapper:** в архиве есть `gradle-wrapper.properties`, но нет исполняемого JAR-файла официального Gradle Wrapper — в среде подготовки не было доступа к его загрузке. Android Studio может импортировать проект, используя дистрибутив из URL в properties. Если Studio требует полный wrapper, установите Gradle 8.11.1 локально и выполните `gradle wrapper --gradle-version 8.11.1`, затем синхронизируйте проект. В большинстве случаев проще выбрать локально установленный Gradle в настройках Android Studio.

> Здесь предоставлен исходный код. APK **не собран и не протестирован на реальном телевизоре**, поскольку в среде создания не установлен Android SDK.

## Управление пультом

| Кнопка | Действие |
|---|---|
| Стрелки ↑ ↓ ← → | Передвигают экранный курсор, когда режим курсора активен |
| OK / центр | Нажимает в точке экранного курсора |
| BACK | Выходит из режима курсора; повторное нажатие — назад по истории |
| MENU | Выходит из режима курсора и переводит фокус на панель |
| CH+ / CH−, PAGE UP/DOWN | Прокручивает страницу |
| Кнопка «● Курсор» на панели | Возвращает управление экранным курсором |
| Кнопка «⋮» | Режим ПК, прокрутка, очистка и подсказка |
| Ctrl+L, Ctrl+R | Адресная строка, обновление (с подключённой клавиатурой) |

Если на вашем пульте нет MENU, нажмите BACK один раз, затем переключайте кнопки верхней панели стрелками. Если CH+/CH− нет, используйте прокрутку из меню `⋮`.

## Ограничения MVP

- Это **WebView-браузер**, а не отдельная сборка Chromium: сайты с DRM/защищённым видео, некоторые OAuth-входы, PWA и WebRTC могут работать не на всех ТВ или вовсе не работать.
- Нет вкладок, менеджера загрузок, блокировщика рекламы и синхронизации аккаунта.
- Сам браузер не запрашивает доступ к микрофону/камере/геолокации и не предоставляет сайтам эти разрешения.
- Обычные HTTP-сайты разрешены для совместимости (см. `usesCleartextTraffic`), HTTPS предпочтительнее.
- WebView должен присутствовать и быть обновлён на устройстве.
