# Как получить APK без Android Studio

В проекте есть GitHub Actions workflow `.github/workflows/build-apk.yml`. После загрузки проекта в GitHub сборка запускается на сервере GitHub, а получившийся **debug APK** подписывается тестовым ключом автоматически. Для установки на телевизор подходит, но для публикации в Google Play нужна отдельная release-подпись.

1. Создайте пустой репозиторий на [github.com/new](https://github.com/new).
2. Загрузите **содержимое папки** `TVRemoteBrowser` в корень репозитория, включая скрытую папку `.github` (не загружайте только ZIP как файл, код должен быть распакован).
3. Откройте вкладку **Actions → Build Android TV APK → Run workflow**. Если сборка запустилась сразу после первой загрузки — можно просто открыть запущенный run.
4. После успешной сборки откройте этот run и скачайте артефакт **TVRemoteBrowser-APK** из раздела Artifacts.
5. Распакуйте его: внутри файл `app-debug.apk`. Передайте APK на Android TV и установите, разрешив установку из неизвестных источников для выбранного файлового менеджера.

Для локальной сборки откройте папку в Android Studio с Android SDK Platform 35 и Gradle 8.11.1, затем **Build → Build APK(s)**.

**Важно:** проект и workflow предоставлены без подтверждённой сборки в этой среде. Здесь не установлены Android SDK/Gradle и нет доступа к серверу сборки. Приложение использует системный Android WebView: если он отсутствует на телевизоре, страницы не откроются. Некоторые DRM-плееры могут не работать в WebView.
